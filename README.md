# \# ShopFromHome

# 

# \*\*ShopFromHome\*\* è un progetto universitario sviluppato nell'ambito di Ingegneria del Software. L'obiettivo è realizzare un'applicazione Android che permetta agli utenti di prenotare la spesa online e ritirarla successivamente, riducendo il tempo necessario per fare acquisti.

# 

# \## Tecnologie utilizzate

# 

# \- \*\*Android\*\* per l'applicazione mobile

# \- \*\*Java\*\* per lo sviluppo Android

# \- \*\*Spring Boot\*\* per il backend

# \- \*\*MySQL\*\* per la gestione dei dati

# \- \*\*Maven\*\* per la gestione delle dipendenze del backend

# \- \*\*Gradle\*\* per la configurazione e la compilazione del progetto Android

# 

# \## Struttura del progetto

# 

# \- `app/` — codice e risorse dell'applicazione Android

# \- `src/` — codice sorgente del backend Spring Boot

# \- `DERIVERABLES/` — documentazione di analisi, progettazione e test

# 

# \## Obiettivo del progetto

# 

# Il progetto mira a offrire un'esperienza di acquisto più rapida e comoda, consentendo di organizzare la spesa prima del ritiro.

# 

# \## Stato del progetto

# 

# Progetto universitario sviluppato nell'ambito di Ingegneria del Software.
